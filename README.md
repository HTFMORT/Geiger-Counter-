# GC-01 Geiger Counter - Custom Firmware

This repository contains the custom firmware and software architecture developed for a Geiger Counter project. This build was awarded 1st place in a high school physics and engineering competition.

## Project Structure: Hardware vs. Software

* **Hardware & Assembly:** The physical circuit and schematic are directly sourced from the excellent open-source design by [pra22/GC-01-Geiger-Counter](https://github.com/pra22/GC-01-Geiger-Counter). Physical assembly, 3D modeling of the custom enclosure, and oscilloscope verification were done in collaboration with my classmate, Tommaso.
* **Software Architecture (This Repo):** The original firmware was not used. The software architecture, core system logic, and hardware integration provided in this repository were designed and written entirely from scratch.

## Development Workflow & AI Assistance

As a maker focused primarily on hardware integration and system design, I optimize my development workflow to meet strict deadlines. 

I design the overarching logic, pinouts, and system architecture manually. To accelerate the coding process, I utilize AI tools (ChatGPT/Gemini) to handle repetitive boilerplate (such as TFT UI coordinate mapping and standard network modules) and to rapidly prototype complex software features I want to explore. This approach allows me to focus my time on high-level engineering, hardware communication, and system orchestration.
